# 🏗️ CityBuild Clicker

Строительный кликер с зонами, ресурсами и прогрессией.

## 🎮 Особенности
- **9 зон** для строительства
- **9 типов зданий** (от фермы до храма)
- **4 ресурса**: 🌾 Пшеница, 🪵 Древесина, ⛏️ Руда, 💰 Золото
- **Улучшения** клика и автоматического производства

## 🕹️ Управление
1. Выберите здание на панели
2. Нажмите "ПОСТРОИТЬ" на пустой зоне
3. Кликайте по зонам для добычи
4. Улучшайте здания для прогресса

## 🚀 Запуск

python main.py
